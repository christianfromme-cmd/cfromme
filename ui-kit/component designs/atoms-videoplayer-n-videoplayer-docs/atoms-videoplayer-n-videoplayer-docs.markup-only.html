N-Videoplayer

Video player component based on Video.js for video playback.

Possible placement:

  • Content area
  • Inside other components like IT01 or STA01

Options:

  • Autoplay
  • Muted
  • Poster image
  • Video qualities (SD/HD)
  • Fullscreen mode

CSS Classes:

Element Description CSS Class Default value
[data-tpl="video"] Video container videoplayer-container
video Video element video-js videoplayer
video Without poster image posterimg
video Fullscreen mode vjs-is-fullscreen
