N-Gallery

Image gallery component based on Swiper.js for displaying multiple images in a slider format.

Possible placement:

  • Content area
  • Inside other components like IT01

Options:

  • Multiple images as slides
  • Pagination dots
  • Autoplay
  • Autoplay speed

CSS Classes:

Element Description CSS Class / Value Default value
[data-tpl="n-gallery"] Main container n-gallery_swiper
.swiper-pagination Pagination dots n-gallery_pagination
<.n-gallery_swiper> data-autoplay boolean true
<.n-gallery_swiper> data-autoplayspeed in ms 2500 2500
