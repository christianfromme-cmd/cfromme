Grids and Colors

All Grids can be displayed with (default) or without energy waves. If you don't want to show them, simply remove the code fragment.

Important: Grids "EXT03-06" require "TEA03r" tile elements as children.

You can choose colors for the grid (background) and for the items itself (teaser etc.). The colour selection can be found below, different combinations are possible.
