TBL02

The TBL02 component is similar to TBL01 in terms of how it operates, placement and the options available to you (striped and bordered).

It allows you to expand the number of columns up to twelve.
Things such as headline and headings are dealt with by the editor.

In addition to TBL01, TBL02 has the option of "fixed". The column width is set and the breackpoint is different.

Possible placement:

  • Content zone
  • Margin column

Options:

  • Striped (default)
  • Bordered
  • Fixed
  • Bordered and fixed
  • Striped and bordered
  • Striped and fixed
  • Striped and fixed and bordered

CSS-Classes:

Element Description CSS-Class Default value
<table> Table style (combination of one or more classes) table-style--striped table-style--bordered table-style--fixed table-style--striped
