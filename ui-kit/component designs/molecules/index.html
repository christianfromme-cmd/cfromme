TEA01r

Teaser with textbox, media and CTA button. The media (image or video) can be placed above or next to the textbox.

Possible placement:

  • Content zone with different grids
  • Page "Blank page": use grid "Full Teaser Grid Width" to display full width media with overlaying text

Options:

  • Image or video
  • Background color of textbox
  • Position of textbox

TIC01

Text element with optional media content. Often used within accordion (ACC01) or slider (SLI01b) elements.

Possible placement:

  • Content zone
  • Margin column

Options:

  • Alignment
  • With or without headline and subheadline
  • With or without image or video
  • Download link for image
  • Zoomable image
  • Expandable text
  • With or without CTA button
  • CTA button color and full width

CSS-Classes:

Element Description CSS-Class Default value
[data-tpl="video"]
[data-tpl="mediaContainer"] Image is zoomable zoomable
