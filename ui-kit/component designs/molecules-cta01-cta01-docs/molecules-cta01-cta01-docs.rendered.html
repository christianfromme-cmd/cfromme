CTA01

Standalone Call-to-Action button. Instead of using a button inside each text element (TIC01, TIC02, TIC03), a CTA can be placed below all elements (representing all of them).

Possible placement:

  • Content zone
  • Margin column

Options:

  • Button color
  • Alignment
  • Title-Attribute (optional)

CSS-Classes:

Element Description CSS-Class Default value
[data-tpl="cta01"] Button alignment cta01--center cta01--right
[data-tpl="cta01"] <a> Button color color-cta--gradient-green-reverse color-cta--blue color-cta-2 color-cta--gradient-green
