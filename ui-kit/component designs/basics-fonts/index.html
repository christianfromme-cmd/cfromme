Corporate font | RWE Sans

Typography can help to give brands a unique look.

Our corporate font, RWE Sans, has been tailor-made to create a distinctive brand presence. It is characterised by clear geometric lines and radiates openness and friendliness.

It has all the styles that are relevant for corporate communications.

The new RWE Sans is available as a True Type Format (RWESans.ttf) and as an Open Type Format (RWESansPS.otf). It is also available in .eot and .woff formats for use on the web.

RWESans

  • Light: "RWESans-Light", font-family: light;
  • Regular: "RWESans-Regular", font-family: regular;
  • Medium: "RWESans-Medium", font-family: medium;
  • Bold: "RWESans-Bold", font-family: bold;
